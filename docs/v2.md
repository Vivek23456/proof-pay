## Product

- Humanship ID integration — sybil-resistant human-unique attestations layered on top of ProofPay.
- Mobile-native iOS + Android apps (React Native or native Swift/Kotlin).
- Fiat on/off-ramp via Stripe Crypto or Circle Mint for merchant cash-out.
- Multi-token support (USDT, PayPal USD, EURC) beyond USDC-only MVP.
- Attestation revocation and dispute flows (merchant-initiated).
- Attestation expiry / rotation — `valid_until` stored on the attestation itself, not just the rule.
- Merchant categories / tags — policy rules that only consider attestations from the same category (coffee, bookstore, salon) to prevent cross-category gaming.
- Customer privacy mode — ZK-based "at least N attestations" without revealing which merchants.
- Creator-collective preset — one creator DAO issues shared policies to member merchants.
- DePIN service access — extend `pay_and_attest` to gate API-key issuance for DePIN nodes.
- OSS bounty payouts — same program, different front-end framing.

## Engineering

- Off-chain indexer service (Helius webhook + Postgres) for fast merchant analytics dashboards.
- Gasless transactions via Jito bundles or account abstraction.
- Compressed attestations via SAS PR #101 (Light Protocol) once merged + audited.
- SDK package (`@proof-pay/sdk`) for third-party merchants to embed the checkout widget.
- Policy DSL — move from struct-based rules to a small expression language ("if `attestations_at_me ≥ 2 and total ≥ 10`, then 15% off").
- Onchain analytics program that aggregates per-merchant attestation counts for dashboards.
- Multi-sig merchant authority via Squads integration (so a DAO can own a merchant registry).
